## 📖 Overview

Sunday Night Worship is a church management application designed to simplify communication, worship planning, and member engagement.

The application provides church leaders with an intuitive platform to manage worship songs, church events, prayer requests, user accounts, and media while giving members easy access to church resources from a single location.

Whether you're organizing a weekly worship service or managing church-wide events, Sunday Night Worship helps reduce administrative overhead and keeps everyone connected.

# 💻 Installation

## Clone the Repository

```bash
git clone https://github.com/aevans01/Sunday-Night-Worship.git
```

Move into the project directory

```bash
cd Sunday-Night-Worship
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm start
```

The application will be available at

```
http://localhost:3000
```
